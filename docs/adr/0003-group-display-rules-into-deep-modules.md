# 按共同变化聚合研究库、阅读核心与展示

用户以降低整体理解与修改复杂度为核心目标，比较统一阅读入口、独立阅读能力和研究库交付阅读器三种方案后，确认采用研究库、阅读核心与展示三项主要职责。研究库聚合资料准备及记录存取，阅读核心聚合同版本内的内容关联、导航与恢复规则，展示负责排版、图形及 PDFKit；普通改动应能找到明确的规则归属。

这一选择减少图解、报告和核对入口之间对版本、来源与位置规则的重复协调，同时让文件 I/O 与阅读语义独立变化。Module 内部继续按具体规则组织，不要求一个大类、多个 Swift Package 或每页一个公开 Module。三项职责的基线已确认，具体 Interface 与实现细节仍按[技术方案提案](../display-app-technical-plan.md)逐项审查，生产代码尚未改动。
