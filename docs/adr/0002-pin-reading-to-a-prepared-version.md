# 阅读会话固定版本，更新单独准备

继续原版、引用定位、最近实际位置，以及阅读核心与研究库的职责已获用户确认，按[技术方案](../display-app-technical-plan.md)实施。

iCloud 中新版研究到达后，App 自动准备并校验，在研究库显示更新；正在进行的阅读继续使用原版本。后续功能讨论已明确：“继续阅读”仍回原版本最近实际位置，“阅读新版”是另一个明确动作。这样保留当前图、计算、依据与 PDF 的一致上下文，接受正在阅读的内容可能暂时不是最新版本这一取舍。

图解和完整报告属于同一研究会话的两种方式，共用研究身份与详情返回关系，各自保留位置。启动回到最近的主阅读位置，详情内部位置在再次进入时恢复；阅读记录按版本区分，不因新版本准备而清空旧记录。
