# Triage Labels

保留五个默认标签，直接应用于 `GRHISMY/InvestmentShowcasePlatform` 的 GitHub Issues。任务是否结束以 GitHub 的 open / closed 状态及关闭原因为准。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求充分明确，可交给 AI 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

技能要求设置某个分诊角色时，使用表中对应标签。切换分诊角色时移除原角色标签，保留其他用途标签。任务完成后关闭 Issue 并移除仍表示等待实施的分诊标签。以后如需改名，修改“本项目标签”列并同步仓库标签。
