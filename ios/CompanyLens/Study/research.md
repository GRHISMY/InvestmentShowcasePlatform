# 格力电器：这门生意怎么样

财务数字从 2020-01-01看到 2026-09-30，使用的资料查到 2026-11-09。

**格力过去赚到了钱，也披露了具体的售后安排。但最近，利润在下降；账上的钱又有不同来路。看懂这家公司，要把“服务做得怎样”“生意赚得怎样”和“股东能拿到多少钱”分开。**

格力主要做空调等产品的生意，也有金融业务和投资。它们怎样赚钱、怎样收钱，要分开看。

我目前最在意三件事：

- **最近一季，利润降得比销售金额快得多。** 2026年第三季度，销售金额比去年同季少约8%，归母净利润却少了约43%。归母净利润，就是公司赚的钱里算给上市公司股东的那一份。它仍然盈利，但最近的表现明显变弱。
- **收到的钱，不一定是这次卖产品新赚的钱。** 以前交存的保证金取回来了，或者以前放出的贷款收回来了，银行账户也会增加。它们和持续卖好产品、收到销售款，是不同的来路。
- **赚到的钱，还要看后来怎么用。** 有些投入没有达到原先的预期；有些钱买了金融产品；还有些要留着还债、付货款和继续经营。不能看到一个大余额，就当作都能分给股东。

对“负责”，我能说得更具体一些：格力不只写了长期包修的口号，还披露了接单、培训、维修跟进和补救安排。但它自报的满意度，不能直接证明每个用户都得到了好服务；这些服务究竟多带来多少生意、多花多少钱，也还没算清。

**这份报告怎么说“钱”：** “销售金额”是财报按规则记下的收入，不保证已经收到钱；“利润”是收入减去相应成本费用后的结果，也不等于银行进账。这里把“格力整体”用于上市公司及其控制的公司合在一起的报表，把“格力本部”用于直接上市、向上市股东分红的那家公司。两种报表看的范围不同。

**时间：** 看2020—2025年全年，以及2026年前9个月；回购进展看到2026年10月底，资料查询截至11月9日。2026年还没有结束。正文讲判断，原始科目、全部计算和更多限制放在[详细依据](evidence.md)，每一段也有直达链接。

想核对数字或原话，可以打开每段后的“依据和计算”。

## 先看格力答应用户和伙伴的事做得怎样

<a id="conclusion-gree-service"></a>

### 格力安排了人和流程做售后，实际效果还要核实

有接单、培训、跟进和补救安排，比一句“服务好”更具体。但用户到底满意不满意，我们还不能只听格力自己说。

2025年的公开报告写了长期包修、统一服务电话、维修进度查询和补救安排。同年，格力自报客户满意度99.97%、投诉解决率100%。这两个数字都来自格力；我们还没拿到调查问了多少人、哪些人没回答，以及怎样才算“解决”的详细说明。

修得好，可能让用户愿意再买；答应修很多年，也意味着公司以后还要花钱。现在还不能算出，这些服务多带来了多少订单、又多承担了多少成本。对用户做事和公司多赚钱，需要分别查清。

**还不知道：**

- 还不知道满意度调查问了谁、哪些人没回答，投诉怎样才算解决；也缺公司以外的人核实的实际服务结果。
- 还缺包修具体适用条件、故障和维修支出明细，不能确认每种产品、每位用户都得到了同样的服务。

<a id="conclusion-gree-partner-financing"></a>

### 先收货款、后付钱，会让账户好看，也带着要办的事

钱先留在格力账户里，不代表都能拿去分红。有些对应着还没交的货、以后要给的返利，或还没付给供应商的款。

2025年报说明，卖格力产品的商家（经销商）会先付货款；年末还记着约485.71亿元销售返利余额。返利就是按合作条件应给这些商家的优惠或款项，它是余额，不是当年新花了这么多钱。公司也说，到年底不存在已过付款期限却还没付给中小企业的钱；这是公司的说法，还不能证明每家伙伴的合作条件都公平。

先收后付可能降低交易风险、让供货更稳定，也可能让伙伴承担资金压力。要查约定是什么、有没有按时做到、双方最后得到了什么。不能一看到应付款多，就说拖欠；也不能把这些钱全当成股东可以拿走的钱。

**还不知道：**

- 缺具体付款期限、付款方式带来的成本、经销商库存、退货和返利实际兑现记录，还不能判断各类伙伴真正承担了多少。
- 还没有拿到另一种确实可行的合作办法及双方成本，不能断言把所有付款期限缩短就一定更好。

## 最近赚钱的情况，哪里变弱了

<a id="conclusion-gree-latest-quarter"></a>

### 最近一个季度，利润降得比销售金额快得多

格力仍在盈利，但2026年第三季度的表现明显转弱。只看前9个月加起来的结果，会把最近的变化看淡。

2026年7—9月，销售金额为366.78亿元，比去年同季少7.97%。归母净利润39.96亿元，少43.31%；按公司披露的规则，把不直接代表日常经营表现的那部分收益和损失扣除后，归母利润为36.96亿元，也少了44.32%。这个数通常叫“扣非归母利润”。所以，这次下降不能只拿那部分收益和损失的波动来解释。

把归母利润与股东平均的账面资金相比，可以看这笔资金赚了多少。公司披露的前三季这个比例也在下降；它不是分红率，也不是买股票的收益。眼下最该查的是：售价、卖的产品组合、成本费用和利息收益，分别造成了多大变化。现在不能把原因全怪到服务、用户不满意或某一个行业因素上；一个季度也不能直接当作全年。

**还不知道：**

- 还缺第三季度按产品、地区和费用拆开的详细原因，不能把利润下降直接说成用户不满意或服务花钱太多。

[依据和计算](evidence.md#conclusion-gree-latest-quarter) · [看原报告第2页](reports/pdf-e7a252db3b7fa083.pdf#page=2)

<a id="conclusion-gree-economic-scarcity"></a>

### 技术和服务要让客户愿意买，公司才有机会赚钱

有技术、有工厂、有服务网点，是做成生意的条件。最后能赚多少，还要看客户为什么选格力，以及别人能不能提供差不多的东西。

格力披露了自己做关键零部件、制造产品，以及安装维修的能力。这能帮助解释它怎样交付产品。可我们还缺同条件的比较：格力是否更耐用、用户使用几年总共花多少钱、贵出的价格有没有对应的好处。不能只数专利和网点，就断定它以后能一直多赚钱。

客户得到好处，公司才更有机会卖出产品；但同样的好处如果别人也能低价提供，利润就可能被压下去。格力留下多少，要一起看售价、成本、竞争和持续投入。

**还不知道：**

- 缺与同类产品在相同条件下的耐用性、全部使用成本和价格比较，尚不能说清格力究竟好多少、客户愿为此多付多少。
- 还没把售价、产品组合、成本、渠道分配和新增投入对利润的影响逐项分清。

[依据和计算](evidence.md#conclusion-gree-economic-scarcity) · [看原报告第12页](reports/pdf-7cc972f2d199e2ec.pdf#page=12)

<a id="conclusion-gree-demand-mix"></a>

### 总销售额下降，不代表每种生意都在同样变差

先看哪一部分变少了。国内的主要业务收入还在增长，但相应成本涨得更快，留下的比例反而变小。

2026年上半年，格力总收入下降8.15%，制造业收入下降2.56%，其他业务收入下降57.87%。国内主要业务收入增长1.90%，成本却增长5.96%；海外主要业务收入下降21.98%。这些部分的变化不一样，不能用一个总数代替所有产品和地区。

收入增加，也未必多赚；收入下降，也不一定全是客户流失。产品价格、卖什么、成本和业务调整都可能有影响。我们还没把它们逐项分清，也不能把上半年的情况直接当成第三季度的情况。

**还不知道：**

- 缺同样范围的终端销量、实际售价、渠道库存和竞争者资料，暂时不能分清各因素的贡献。

<a id="conclusion-gree-history-cycle"></a>

### 过去恢复过，最近又回落，不能照旧速度往后推

格力过去有过不错的恢复，但最近销售金额和经营利润都在回落。历史上的好表现，不能替未来打包票。

为了按同一办法比较，我把产品和服务业务的主要收入、成本费用放在一起，并把相应利息收益单独分析。这项自算指标叫“核心利润”，不等于现金。2020年约185.35亿元，2024年约284.55亿元，2025年回落到约270.40亿元。总收入也从2023年的2039.79亿元降到2025年的1704.47亿元。

这些数字说明最近在回落，不能保证以后会继续跌，也不能照过去恢复时的速度预计增长。要看接下来的产品、价格、成本和用户选择，能不能让经营重新变稳。

[依据和计算](evidence.md#conclusion-gree-history-cycle) · [看原报告第99页](reports/pdf-0d3c39090adf97fe.pdf#page=99)

<a id="conclusion-gree-profit-driver25"></a>

### 2025年利润少降一些，有成本费用下降的帮助

销售金额少了，账上记下的成本费用也少了，所以利润没有少那么多。费用下降不等于当年少付出了同样多的现金。

2025年收入比2024年少约187.17亿元，营业成本少约138.55亿元。两者相减后，毛利少约48.62亿元；毛利就是收入扣掉对应营业成本后剩下的部分，还没扣其他费用。其他费用等变化抵消了一部分下降，按本报告办法算的核心利润少约14.15亿元。

降低成本费用能帮忙，但要看怎么降的。有的可能是效率提高，有的可能跟业务规模变小有关。是否影响研发、质量和售后，仍要查，不能只看到费用下降就说经营更好了。

**还不知道：**

- 还没分清销量、售价、产品组合、返利和售后成本各造成多少变化。

[依据和计算](evidence.md#conclusion-gree-profit-driver25) · [看原报告第88页](reports/pdf-7cc972f2d199e2ec.pdf#page=88)

<a id="conclusion-gree-profit"></a>

### 先分清利息记在哪里，再看产品生意赚了多少

格力除了做产品，也有做金融业务的公司。报表里不同位置的利息，不能当成同一笔，扣两次或漏掉。

2026年前9个月，报表中有金融业务的利息收入，也有放在“财务费用”里、用来抵减费用的利息收入。按本报告一直使用的算法分开处理后，核心利润约159.49亿元。这个数是研究用的记账利润，不是银行收到的钱，也不等于报表中的归母或扣非利润。

把不同生意的收入和费用混起来，就容易误判空调等业务赚得怎样。完整算式可以查证；但短季报没有给足产品、价格、返利和售后明细，利润变化的原因还没全分清。

**还不知道：**

- 季报没有给足产品、价格、质保和返利明细，尚不能完整解释利润为什么变了。

[依据和计算](evidence.md#conclusion-gree-profit) · [看原报告第6页](reports/pdf-e7a252db3b7fa083.pdf#page=6)

<a id="conclusion-gree-warranty-rebates"></a>

### 费用换了一栏，不代表修理成本消失了

同一笔费用改记到另一栏，不能因此说公司更省钱了。答应修很多年，今后该做的服务仍然要做。

格力曾把销售返利改为从收入里扣；又把2023年约23.28亿元用于产品质量保证的那类费用，从销售费用改列到营业成本。这样会改变毛利率、销售费用率的样子，但光是换位置，不会让这笔总成本自动减少。

比较几年利润时，先把记账方法对齐，再讨论效率有没有提高。更重要的是，以前计下的质保成本，后来实际用了多少、退回或调整了多少、修得怎样；目前还缺完整明细。

**还不知道：**

- 缺以前计下的返利、质保成本后来实际用了多少、调整多少，以及维修效果的完整明细。

## 收到的钱，哪些来自可以持续做下去的生意

<a id="conclusion-gree-cash"></a>

### 2025年多收到的钱，很大一部分与取回保证金有关

以前交存的保证金取回来了，这笔钱就进了账，但不是今年新赚出的利润。

2025年，格力整体日常经营收到的钱减去付出的钱，比2024年多约170.14亿元。保证金从上一年净存入，变成本年净收回。拿这两年相比，仅这一项就使净收款多约166.18亿元；它不是说2025年就净取回了166.18亿元。

因此，不能把2025年这次改善全部当成产品生意更赚钱，也不能假设下一年还能取回同样多的保证金。还要分开看销售收款、供应商结算和金融业务的钱。

**还不知道：**

- 缺财务公司单独的现金收支表，2026全年资料也还没出，暂时不能把整体净收款拆成一份完整的产品业务现金账。

[依据和计算](evidence.md#conclusion-gree-cash) · [看原报告第29页](reports/pdf-7cc972f2d199e2ec.pdf#page=29)

<a id="conclusion-gree-2026-cash-drivers"></a>

### 2026年销售收款减少，收回贷款补了一部分

公司从销售收到的钱少了，收回以前放出的贷款帮忙补了一部分。收回本金，不是又卖了一批空调。

2026年前9个月，格力整体经营收支相抵后净收到约240.63亿元，去年同期是457.28亿元。销售收款从1399.90亿元降到1136.92亿元；贷款本金的净回收，对两年的差额反而多贡献约48.50亿元。

要判断以后能不能持续收到钱，就要看产品销售能否稳定带来收款。贷款收回能帮当前周转，但不能一直代替新的销售。销售收款也不直接等于用户买了多少台，还受业务组合和收款时间影响。

[依据和计算](evidence.md#conclusion-gree-2026-cash-drivers) · [看原报告第8页](reports/pdf-e7a252db3b7fa083.pdf#page=8)

<a id="conclusion-gree-finance-boundary"></a>

### 合在一起的报表，不能全当作工厂卖产品的成绩

格力整体既有产品生意，也有金融业务。看见整体收到了钱，不能就说这些都是卖空调赚来的。

格力控制一家财务公司，金融业务的放款、收回贷款等会进入整体报表。格力本部自己也经营、持有其他公司股权并调度资金。把整体报表减去本部报表，还包含内部交易被抵掉等差异，不能直接得到所有子公司的真实单独成绩。

想看工厂究竟赚了多少、哪些钱能持续分给股东，需要按真实业务和公司分别核对。现在没有拿到足够连续的财务公司和格力钛单独报表，这一部分只能说明到现有材料支持的程度。

**还不知道：**

- 尚未取得2023年以后财务公司和格力钛连续完整的单独利润、现金和债务报表。

[依据和计算](evidence.md#conclusion-gree-finance-boundary) · [看原报告第185页](reports/pdf-7cc972f2d199e2ec.pdf#page=185)

<a id="conclusion-gree-maintenance-capital"></a>

### 2025年买设备花得少，不代表以后都不用花

公司要继续做出可靠产品，就得维护、更新设备并留够经营用的钱。不能把今年少买设备，直接当成以后都能多分红。

2025年，格力整体买建厂房、设备等长期资产实际付出约17.17亿元。把它从经营净收款里减掉，得到约446.66亿元，但这只是一个简化算式。它没有分清经营收款的来路，也没说明设备维护和扩张分别需要多少钱。

同年，账上把旧固定资产成本分摊到本年的金额约44.88亿元，这叫折旧；它不是今年又付了一次现金，也不能直接当成维护预算。因此，不能用折旧和买设备付款的差额，断定公司少维护了多少，更不能把446.66亿元全当作能分给股东的钱。

**还不知道：**

- 缺设备更新、维持与扩张花费、产能使用和最低经营用钱的明细，暂时算不出能长期稳定分出去的准确金额。

## 赚来的钱，后来投到了哪里

<a id="conclusion-gree-financial-assets"></a>

### 越来越多的钱放在两类金融资产里，要单独看效果

公司买金融产品、到期再买，会产生很大的收付款记录。这不等于又建了同样多的工厂。

报表中的“交易性金融资产”和“其他债权投资”两项相加，从2024年底约235.65亿元，增到2025年底553.99亿元、2026年9月底723.76亿元。这只是两项之和，不是所有金融资产，也不能直接称为全部闲钱。

这些钱买了什么、赚多少、什么时候能取回、有没有限制，会影响公司以后能用多少钱。产品本金来回滚动和真正赚到的收益要分开；目前还缺逐项合同和期限对照。

**还不知道：**

- 缺各笔金融产品的期限、取回条件、风险和实际持有人清单。

<a id="conclusion-gree-project"></a>

### 格力钛的一些项目停了，投资没有达到原先预期

格力控制的格力钛有部分工程停建，2025年新增记下约9.96亿元减值。减值的意思是：按现有判断，资产值不了原来账上记的那么多，需要把账面价值调低；不是今年又付出了9.96亿元现金。

这是评价投资成绩的重要证据。还要继续查以前一共投入多少、实际收回多少、剩余项目和债务责任如何处理。不能把原价、历年减值和本年新增减值再加成几笔互不相干的损失。

**还不知道：**

- 缺格力钛完整的历史投入、实际收回款，以及剩余还款责任和追偿结果。

### 本部的股权账和项目自己的账，不能把损失直接相加

一边记“持有这家公司股权的价值”，另一边记这家公司里面的项目。两层账要先对清，不能看到两边都减值，就算作又亏了两次。

2025年末，格力本部持有格力钛股权的原账面金额约28.46亿元，已计的减值也是约28.46亿元，这项股权在本部账上的剩余价值为零。整体报表还会看格力钛内部工程等资产，和本部股权属于不同层次。

要问这笔投资究竟损失了多少现金，必须对应资金投入、内部往来和底层资产，排掉重叠。股权账面减到零，也不代表以后不会再有其他付款或还款责任。

**还不知道：**

### 盾安一项业务的估值，只比账上价值高一点

未来卖多少、赚多少以及估算条件，都影响这个结果。公司当时没有为这组业务记减值，不能据此说以后都安全；别的业务估值高，也不能自动替这组业务抵掉风险。

## 股东拿到了什么，哪些还只是计划

<a id="conclusion-gree-parent-cash"></a>

### 要分红，得看格力本部手里实际能用的钱

整体报表里的钱，不一定都能马上拿到本部。分给上市股东之前，先要看本部的钱从哪来、能不能用、还要办哪些事。

2025年，格力本部有自己的经营收款，也有大额“其他经营收款”。后一项没有完整拆清每笔来路，可能包含内部资金调度等，不能全当成新卖产品赚来的钱。

未来能分多少，还要留出经营所需、支付已有义务，并核对存款和借款到期。过去确实分过红，不等于现在看到的所有本部收款都可以继续分。

**还不知道：**

- 还没拆清内部资金来路、哪些钱受限制，以及子公司能把多少钱、何时交到本部。

<a id="conclusion-gree-cash-availability"></a>

### 账上有很多钱，不等于这些钱都能马上拿去花

有些存款存了较长期限，有些受用途限制。它们仍是资产，但能不能提前动、代价多大，要看具体约定。

2025年底，格力整体账上“货币资金”约1105.53亿元。扣掉不算入现金及现金等价物的定期存款和利息约724.09亿元，以及受用途限制的资金约105.78亿元，余下约275.66亿元。这是现金流量表采用的期末现金范围，合计名称是“现金及现金等价物”；其中“现金等价物”一栏本身没有单独列金额，不能把275.66亿元全称为现金等价物。

不算在这个余额里的定存，并不一定完全不能提前取；要看合同和取款代价。这个余额也不是已经为股东留好的分红。上述是2025年底的细项，不能直接拿来代替2026年9月底的情况。

**还不知道：**

- 三季报没有给足定存和受限资金的期限明细，本部最低要留多少钱、子公司资金能否转过来也还没查清。

<a id="conclusion-gree-debt-maturity"></a>

### 手里有钱，也要看还款日是不是快到了

存款和借款不能只做一个相减。钱什么时候能拿到，债什么时候要还，同样重要。

2026年6月底，按本报告列明的借款范围，格力整体借款约828.81亿元，其中短期借款和一年内到期的长期借款约807.52亿元。到9月底，短期借款约807.62亿元。公司也持有大额存款和金融资产，这些都要按期限和所在公司对应起来看。

现有资料并没有证明公司已经还不起债。但能否继续借到钱、利率怎样、资产何时能取回，会影响能留给经营和股东的资金。不能只用一个净额把这些时间差抹掉。

<a id="conclusion-gree-dividend"></a>

### 分红哪年决定、哪年付钱，是两件事

去年已经决定分的钱，可能今年才付出去。所以，数“今年付了多少”和看“今年利润余额扣了多少”，不能混在一起。

一笔2025年已通过的分红，约55.85亿元，在2026年1月实施；另一笔2025年度分红约112.02亿元，在2026年8月实施，11月后续公告也确认已完成。前一笔已在2025年决定分配时扣减利润余额，今年付款时不能再扣一次利润。

这解释了为什么后来一张利润余额表，只扣了约112.02亿元，却不能据此说2026年1月没有付款。要核对股东实际得到多少，应按每笔分红的实施记录来数；本报告没有把所有历史现金付款都逐笔整理完。

**还不知道：**

- 所有历史分红还没有整理成逐笔、不重复的现金清单，另有少量应付股利差异未对清；本段不能代替完整付款流水核对。

<a id="conclusion-gree-dividend-proposal"></a>

### 新提出的分红，还不是已经到股东手里的钱

“准备分”要和“已经分”分开。利润余额很大，也不等于银行里有同样多的钱可以随时付。

2026年10月26日，董事会提出中期分红：拟每股1元、合计约55.53亿元。公告说还要交股东会审议，最终总额也会随有权分红的股数变化。公告同时列出，本部可供分配的账面利润余额约915.61亿元；这是历年累计的会计余额，不是一张银行余额单。

目前可以确认的是公司提出了方案，不能把这55.53亿元加进已经付出的分红。最后能付多少、何时付，还要看批准、资金和实施记录。

**还不知道：**

- 这组资料还没有后续股东会、最终实施和付款记录，所以只能算预案。

<a id="conclusion-gree-buyback-execution"></a>

### 回购已经在付钱，但最后怎样用还要接着看

公司买回自己的股票，和后来把股票注销，或者交给员工，是不同的动作，不能重复算作又多给了一笔回报。

2026年这次回购获准用50亿至100亿元；到10月底，公司披露实际累计付了约24.04亿元，不含交易费用。9月底报过的约10.83亿元已经包含在里面，不能再相加。公司计划至少把70%的回购股份注销，也就是取消这部分股份；计划不等于已经完成。

回购的钱直接付给卖出股票的人。留下来的股东最后得到什么，还要看回购价格、注销和员工激励怎样执行。不能把批准上限当成已经付出的金额，也不能把旧库存股转给员工当成又花钱从市场买了一次。

**还不知道：**

- 这组资料没有给出本轮回购股份已经注销的结果，后续要继续查公告。
